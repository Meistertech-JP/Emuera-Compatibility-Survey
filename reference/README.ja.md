# 命令リファレンスの使い方

[English](README.md) · [リファレンスを開く](../docs/survey-browser.html) · [用語集](glossary.html) · [文献と出典](SOURCES_ja.md)

ブラウザでクリックできるオフラインの入口は [`index.html`](../index.html) です。

ZIPを展開して `docs/survey-browser.html` をブラウザで開いてください。サーバーやインターネットへの接続は不要です。694対象を名前・説明・要件から検索できます。名前の完全一致が先頭に表示され、同名の式中関数とメソッドの命令形式は別項目になります。

検索・対象種別・判定に加えて、利用目的による「機能ジャンル」で絞り込めます。694対象すべてに一次ジャンルを1件割り当て、必要に応じて副ジャンルを付けています。一次ジャンルの合計は694件で、副ジャンルは複数ジャンルからの検索を可能にする重複所属として、各ジャンルの件数に含まれます。正本は `reference/genres.json` と `reference/target-genres.json` です。

保存画面には「画像を固定」があります。固定した画像は画面内パネルに表示されたまま本文をスクロールでき、対応ケースID・記録種別・役割とともに確認できます。固定は1枚で、別の画像を固定すると切り替わり、固定解除で通常の本文表示へ戻ります。言語切替でも固定画像と対応関係は保持されます。画面幅が狭い場合は本文を覆わない下部パネルに切り替わります。

一覧の閲覧中に検索操作を続けたい場合は、画面右上に常に表示されている「メニューを固定」を使ってください。タブ・検索・判定・対象種別・機能ジャンル・件数表示を画面上部に固定したまま本文をスクロールできます。どのスクロール位置からでもワンクリックで固定・解除でき、ページ冒頭へ戻る必要はありません。邪魔なときは同じ操作で通常表示へ戻せます。既定は通常表示で、設定はブラウザに保存され、言語切替でも選択したモードを保持します。

一覧から「使い方・期待結果・比較・証拠を読む」を開くと、機能、構文、引数、独自の使用例と期待効果、保存された本家・PyEmueraの比較、検証要件、証拠の順に参照できます。名前が完全一致する検索では、その対象の詳細を開きます。関連対象・ケースのボタンから移動できます。

既定は日本語です。ページ上部の言語ボタンで解説本文と表示項目を英語に切り替えます。日本語表示の要件欄では、平易な説明、日本語訳、折りたたまれた英語原文と出典属性を別々に読めます。原ログ、診断文、ソースのコメントは、原文の言語を保ちます。

言語切替では、読み込んだ一覧件数と開いていた欄を保持します。説明用の構文記号は英語では `syntax_en` がある場合にその表記を使い、実例の日本語リテラルは変更しません。互換性欄では差異のある条件を先に案内し、保存記録に該当欄がある場合だけ、完了欄 `done` と診断を実装別に抜粋します。`done` を自然終了の証拠と扱わず、状態配列の意味や不具合数を自動で推定しません。

## 何を根拠にした説明か

説明欄の「説明の根拠」で資料名・版・ソース位置を確認できます。本家C#ソースのリンクは同梱原ZIPから生成した行番号付き表示を開きます。SHA-256は改行や文字コードを変える前の元memberの値です。アーカイブと第三者表示も残しています。外部資料へのリンクは出典確認用で、ページを開くだけで自動取得しません。

- `DOCUMENTED_ORIGINAL`: 元プロジェクトの資料、または実際に取得した保存版に記載された内容。個々の文章の著者が確認できるとは限りません。
- `DOCUMENTED_MIRROR` / `MIRROR`: 移植・保存資料。移植されたことと原著者の確定は別です。
- `DOCUMENTED_DERIVATIVE` / `DERIVATIVE`: 派生版の資料。派生版独自機能を本家v24の仕様とはしません。
- `SOURCE_CONFIRMED`: 固定した本家1824+v24の実装から確認した説明。実機でその例を新規実行したという意味ではありません。
- `NATIVE_OBSERVED` / `PYEMUERA_OBSERVED`: 保存された実行で観測した結果。エンジン・入力・設定・条件は証拠ごとに確認します。
- `EXAMPLE_DERIVED`: 根拠から独自に作成した使用例。期待効果を示し、保存観測とは分けます。
- `UNCONFIRMED`: 説明の根拠や条件を確定できない部分。項目ごとに理由を示します。

各対象の「比較判定」は既存調査の有限範囲の判定です。例の期待結果、説明の充実度、全入力での互換性を表す判定ではありません。共有実行のログ全体が、そのケース固有の出力とは限りません。GUI描画については、本家での機能とPyEmueraのCLIで扱う範囲を区別しています。

要件の `CASE…` は原票の別名識別子です。既存の公開対応表で確認できる11種類は公開ケースへリンクし、それ以外は原識別子を保持して個別対応表がないことを表示します。対象全体の「関連ケース」は別に参照できますが、それらを各要件との直接対応と推定していません。

旧要件と同梱ソースの記述が食い違う、または共通文の適用範囲が広すぎる14件には、「原要件を読む際の注記」を表示します。TRY*LISTの全件不在時の続行先、GOTOリストの引数、複合代入の専用経路に関するものです。原文・訳・元判定を訂正した実機結果へ置き換えず、`requirement-notes-input.json` に独立したソース確認の注記として管理します。

## 編集と再生成

必要な環境はPython 3.10以上、標準ライブラリのみです。リポジトリのルートで実行します。外部サイトや元の開発フォルダーは参照しません。

```sh
python -B tools/survey_browser/prepare_reference.py
python -B tools/survey_browser/build_survey_browser.py
python -B tools/survey_browser/prepare_reference.py --check
python -B tools/survey_browser/build_survey_browser.py --check
python -B -m unittest discover -s tests -p "test_reference*.py" -v
```

`entries-*.jsonl` は対象ごとの独自解説原稿、`requirements-ja-*.jsonl` は要件の訳と平易な説明の原稿です。生成器が `entries.json`、`requirements_ja.jsonl`、`source-locations.json`、ソース閲覧ページ、用語集HTMLを生成します。`genres.json` と `target-genres.json` は機能ジャンルの正本データで、ビルド時に既存リファレンスと結合し、対象・ジャンル・副ジャンルの整合を検証します。要件原文とその属性は `evidence/694-target-trace-20261117/requirements/requirements.jsonl` と照合し、変更・欠落・重複があれば停止します。

`sources.json` は文献の取得時点・保存URL・版・権利・限界の索引、`glossary.json` は専門用語の対訳です。ブラウザは生成時に解説を結合しますが、`results/survey.json` や元要件・証拠の観測値・判定は編集しません。

配布manifestは完成したファイル集合を固定する記録です。再生成・編集後は以前のmanifestとの一致を主張せず、公開集合の監査と新しいmanifestの作成を行います。

## 権利と限界

解説と使用例は、ソースと文献の技術的事実を参照して独自に執筆しています。第三者文献の本文cacheや逐語訳は配布しません。MITは権限のある独自部分に適用され、同梱本家ソースや第三者の文章をMITへ変更しません。[権利表示](../LICENSES/README.ja.md)を確認してください。

出典の版、作者、移植の同一性を確定できないものは[文献調査](SOURCES_ja.md)にその範囲を記載しています。資料が存在すること、保存証拠の原バイトが一致すること、ある例が実行可能であること、歴史的な全観測を第三者が再現できることは、それぞれ別の確認です。
