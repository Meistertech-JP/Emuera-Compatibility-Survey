# Historical Emuera Distribution Preservation

[日本語](README.ja.md)

This directory contains the public catalog and preservation guide for historical Emuera distribution archives. The original distribution archives themselves are available from the preservation Release package.

## Scope

The scope is 208 historical Emuera distribution archives (112 in 7z format, 96 in zip format) distributed via the era community public upload site (ux.getuploader.com/ninnohito). The leading number in each filename is the original upload number. Archives that share a version label but contain different executables, such as 483, 484, and 485 all labeled v17, are distinguished by these numbered filenames.

## Published Materials

- [catalog.json](catalog.json): the public catalog of all 208 archives. It records each archive's SHA-256, MD5, size, format, upload number, distribution URL candidate, and nested file-level measured hashes with content inventory.
- Preservation package **Emuera-preservation-archives-20261119.zip**: a Release asset containing all 208 archives byte-for-byte. The included SHA256SUMS.txt allows full verification.

The compatibility survey baseline, Emuera1824+v24, is upload number 493. See the corresponding entry in the catalog.
