# 歴代Emuera配布物の保全

[English](README.md)

このディレクトリは、歴代Emuera配布アーカイブの公開目録と保全案内をまとめています。元の配布アーカイブそのものは、保全用Releaseのパッケージから取得できます。

## 対象

eraコミュニティの公開アップローダー（ux.getuploader.com/ninnohito）で配布された歴代Emuera 208アーカイブ（7z 112件・ZIP 96件）を対象とします。ファイル名の先頭にある数字は、元のアップロード番号です。同じ「v17」でも実行ファイルが異なる483・484・485など、番号付きの保存名で区別できます。

## 公開物

- [catalog.json](catalog.json)：208アーカイブの公開目録。各アーカイブのSHA-256・MD5・サイズ・形式・アップロード番号・配布URL候補・入れ子ファイル単位の実測ハッシュと内容目録を記録しています。
- 保全パッケージ **Emuera-preservation-archives-20261119.zip**：208アーカイブを元のバイトのまま収めたReleaseアセット。パッケージ内の SHA256SUMS.txt で全件照合できます。

## 利用条件

これらは元の配布者による歴史的な再配布物です。EmueraのソースコードはMITライセンスで配布されています。個々の配布アーカイブの再配布条件は、配布時の条件に従います。この保全パッケージは、元の作品に対して追加の権利を主張するものではありません。

## 調査基準との対応

互換性調査の基準であるEmuera1824+v24は、アップロード番号493のアーカイブです。目録の該当エントリーで確認できます。
