# 範囲・結果の読み方・環境

[English](../en/method.md) | [概要](../../README.ja.md)

基準はEmuera 1.824 +v24、比較対象はPyEmuera 3.0.0です。対象のtyped keyは、同じ名前でも命令、式関数、式関数の命令形式を区別します。静的な登録、ソース調査、画面の表示、実行時の比較は異なる証拠です。

主対象の判定は、それぞれ選択した有限の要件を対象とします。本家Emueraの観測は今後の実装の参照とし、PyEmueraとの比較は互換性修正や回帰確認に役立てます。実証された差異や対象側の診断は結果として残します。観測や実行条件を確定できないケースはそのまま示し、同一対象の別ケースの成功から補いません。全入力の構文挙動や完全互換は実証範囲に含めていません。

元調査ではAIを用いた実装・調査・レビューと、実機での観測を組み合わせました。別エージェントによるAIレビューは、外部の人間による第三者監査ではありません。ハッシュは保存されたバイト列を識別するもので、それ自体は意味論の一致や来歴の真正性を証明しません。

ハーネスは少数の純粋式と、引数エラー、停止位置、副作用、GUI入力の固定ケースを扱います。本家GUIの実行にはWindowsが必要です。環境記録には、別途入手するPyEmuera 3.0.0と保全した本家実行ファイルのSHA-256が載っています。基準アーカイブは改変せず、[基準配布物の案内](../../vendor/emuera/README.ja.md)と一体で配布します。構成物ごとの適用条件は[権利表示](../../LICENSES/README.ja.md)を参照してください。[ハーネスの説明](../../harness/README.ja.md)・[環境記録](../../manifests/environment.json)・[基準アーカイブの同伴NOTICE](../../vendor/emuera/README.ja.md)を参照してください。

候補のルートから、`python -B results/verify.py` で中立データ、`python -B results/test_verify.py` で検証器の選定済み対照ケース、`python -B tools/query.py SET` で対象名を確認できます。代表4ケースには選定した証拠があり、確認できる範囲はケースごとに異なります。候補だけで過去の調査全体を独立に再現できることは確認されていません。[代表的な差異](../../differences/representative-20261116/README.ja.md)・[オフライン検証](offline-validation.md)・[旧形式の証拠参照](results.md#旧形式の証拠参照)を参照してください。

`python -B tools/verify_environment.py` で同伴NOTICE付きbundle、内側ZIP、設定の同一性を確認できます。展開したエンジンも確認する場合は `--native <パス>`、`--pyz <パス>` を指定します。この検査はエンジンを実行しません。
