# Native Emuera GUI: saved finite observations

[日本語](README.ja.md) · [Machine-readable index](cases.json)

These nine Native-only saved conditions use fixtures distinct from the earlier 38 cases; their configuration file is shared. They do not change those case verdicts, establish PyEmuera agreement, or prove complete functionality. The table links each ERB, configuration, UTF-16 Native history, and image crops. Neither the engine nor the original ZIP is included.

History values, visible appearance and internal image values are separate observations. Crops are reduced portions of the screen and do not prove all pixels or exact screen coordinates. Natural exit was not observed in any condition. For images without individual capture receipts, filenames and file modification times do not establish source, phase, capture time or action order. Saved capture records do not retrospectively authenticate operating-system state or input-event timing.

Each image in `cases.json` states whether a capture record exists. Where present, the index summarizes the UTC bracket, phase and SHA; these are not the input-event time. Filenames alone do not establish image content or ordering.

## Saved bytes and verification

`native-history.bin` is the unmodified original log, readable as UTF-16 with BOM. ERB and configuration are also byte copies. Recorded pre/post input hashes and copied bytes were checked. History, images and hashes do not by themselves establish third-party replay or author authenticity.

From this directory, verify the complete file set and hashes as follows. Check the manifest SHA through a separately trusted channel.

```text
python -I -B tools/file_set_manifest.py verify --manifest manifest.json --root gui=.
```
