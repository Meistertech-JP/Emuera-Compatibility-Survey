# 検証要件索引（暫定公開候補）

694の型付き対象と3,359件の検証要件を、凍結された元資料に帰属させた索引案です。これは公開承認済みの配布物ではありません。要件文中の `review` 等は元資料の条件を保持しています。実施済みの結果や新たな実行指示を表すものではありません。元文中に記録された既存観測についても、元資料への帰属を示しており、この索引による再実行や実証ではありません。

`requirements.jsonl` の各行に型付き対象、原文SHA-256、元票のケース関係と文章があります。`verbatim` は元文、`neutralized` は限定的な文言変更です。原文SHAは元文をUTF-8化した値で、真正性、権利や観測結果を単独で証明しません。元資料と原pointerは同梱せず、`source_record_id` は別途保管される対応表用の識別子です。

`targets.jsonl` の `existing_projection` は別途管理する既存結果を参照します。`pointer` は `index.json` にSHAを記した既存結果内のJSON Pointerであり、元資料のpointerではありません。既存結果はこの要件ディレクトリには含まれず、同じ候補配布単位のresultsにあります。roleには原票・case登録・過去の別名判断に基づき索引側で導出したラベルが含まれ、その意味を独立再監査していません。ケースやroleから独立実行を推定することはできません。

本文に現れる技術的ケースIDは原表記を保持しています。`case-id-crosswalk.json` は本文中で正確に識別でき、固定した既存結果にも登録がある11種類だけをケース別名に対応付けます。複合・省略表記の一部分を別名に置換していません。元文のケース群を示す略称はそのまま保持し、群の厳密な構成は確定していません。過去の記録上のラベルやケース参照は、それ自体が証拠の公開や観測の再確認を意味しません。

Python 3の標準ライブラリでオフライン検証できます。独立した信頼経路で入手したpinを指定してください。既存結果ファイルも手元にある場合は、その固定SHAとケースIDを追加照合できます。

```text
python verify.py --manifest-sha256 <manifestのSHA256> --verifier-sha256 <verify.pyのSHA256>
python verify.py --manifest-sha256 <manifestのSHA256> --verifier-sha256 <verify.pyのSHA256> --survey <survey.json>
```

manifestは自身を含まず、pinの信頼性は別途確保する必要があります。機械的な内容・プライバシー検査は網羅的な保証ではありません。著作権主体と許諾範囲は未確定で、公開前には内容・権利・プライバシーの別途レビューが必要です。
