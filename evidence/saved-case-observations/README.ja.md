# 保存済みケースの観測抜粋

[English](README.md)

[観測データ](observations.json)は、保存済みの比較票と実行ログから抽出した主シナリオ1,780件の結果を格納します。[閲覧ページ](../../docs/survey-browser.html)では既存の1,075件とあわせ、主2,898件のうち2,855件を確認できます。残る43件は、旧試行で有効な観測を得られなかったケースです。

結果は凍結ケース台帳のケースIDで照合し、比較票の該当行、ケース固有の識別子、または一致する実行条件で対応付けています。ログは観測に関係する行を選んでUTF-8のJSONに格納しています。ハッシュ付きの抜粋には元資料のSHA-256を記録し、比較票に該当箇所があるものはそのJSONポインターを記録しています。ケースによって観測できた実行系や条件が異なります。

`registry_sha256` は凍結台帳の識別子です。抜粋の読み取りと、原票全体のハッシュ検証や同じ環境での再実行は、別々の検証項目です。[旧形式の参照索引](../legacy226-source-locator-20261118/README.ja.md)で原証拠の可用性を確認できます。
