# 旧監査の型付き資料対応：269対象

[English](README.md)

この資料は、旧監査で記録された資料の対応を示します。`layer.json` は、現行の対象票に `current_acceptance` 欄がない269 typed対象を列挙します。欄がないことは、受入資料そのものがないことを意味しません。記録された有限範囲の判定は変更していません。

旧監査が型付き資料を識別した205対象は `TYPED_SOURCE_IDENTIFIED`、識別していない64対象は `TYPED_SOURCE_NOT_IDENTIFIED` です。後者は旧監査で未特定という意味で、資料が存在しないという断定ではありません。前者も資料名・内容・受入の十分性を外部から確認できたという意味ではありません。

`history` は旧監査の作成時刻・監査ファイルSHA・当時の対象票SHAを示します。205対象の `historical_source_sha256` は、その旧監査で識別された資料のSHAです。これは**現行の受入欄のSHAではありません**。64対象は `null` です。原文はこのlayerに同梱せず、外部で原文未検証です。SHAだけでは内容、同一条件、観測、権利や真正性を検証できません。

`candidate_snapshot` のpathは、同じ配布単位のルートからの相対pathです。各対象のpointer・case recordは、そこに記載したSHAのsnapshotでのみ有効です。37 case参照は直接caseと関連文脈を区別し、共有実行・dead branch等の限界は参照先の記録を確認してください。参照先の記録は非公開の旧原票を外部検証可能にするものではありません。

旧監査のcategoryとgap codeは**旧時点の状態**であり、現在も未解決と判定したものではありません。全行の公開審査は `PENDING` と記録されています。本文、資料SHAの公開適性、権利・privacy、原票の外部提供および配布条件は確認が必要です。セッション本文や個人pathは含みません。

このlayerの調査素材の権利主体・利用条件は未確定です。[資料の権利表示](../../LICENSES/README.ja.md)は参照先であり、そのライセンスがこのlayer全体に適用されることを示しません。
