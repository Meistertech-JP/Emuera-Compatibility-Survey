# 旧形式226対象の証拠参照

[English](README.md)

この[索引](locator.json)は、旧形式のアダプターを必要とする226対象の2,476参照を収録します。元の有限範囲判定は一致82、差異69、条件付き差異75です。受入の直接参照がない対象も、関連ケースの保存結果を[閲覧ページ](../../docs/survey-browser.html)から辿れます。

| 分類 | 閲覧・検証できるもの |
|---|---|
| `PUBLIC_INCLUDED` | 候補内の相対パス、またはそのZIPの指定メンバーから取得できる原本バイト列 |
| `PUBLIC_DERIVED` | ケースID・JSONポインター・元資料SHA-256を持つ公開用の観測抜粋 |
| `EXTERNAL_FETCHABLE` | 外部の正規配布から同一性を検証して取得できる資料 |
| `PRIVATE_RETAINED` | 索引と同一性情報。原証拠は保全され、公開物からは取得できません |
| `MISSING_OR_UNVERIFIED` | 原証拠の所在または同一性が未確認の参照 |
| `REDUNDANT_REFERENCE` | 同じ検証要件を別の公開証拠が満たす参照 |

実件数は索引の `reference_class_counts` を参照してください。相対パスは候補ルート基準です。アーカイブ内の場合は `archive_members` を外側から順に辿ります。同一バイト列を共有する参照でも、元の条件と役割は個別に管理しています。`candidate_exists` は候補から原本バイト列に到達できる場合にのみ真です。

ファイル名が異なるコピーも、原本とのサイズ・SHA-256一致で結び付けます。空の出力ファイルを含み、これは参照先のバイト列を検証できることを表します。実行した事実や条件は、各ケースの観測記録と実行レシートの範囲で確認します。

候補ルートで `python -B tools/verify_saved_evidence.py` を実行すると、収録原本と公開抜粋への参照を検証できます。歴史的な226対象全体の独立再現は未成立です。
