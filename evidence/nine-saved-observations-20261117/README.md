## Division by zero during helper evaluation

Each slot 1, 2 and 3 is a separate condition for INRANGE and LIMIT. The fixture vector is `(4,4,8)`, but the designated helper evaluates `1/C` with `C=0` and does not return, so not all arguments necessarily reach the command. The reached helper counts are 1/2/3, with order 1/12/123. At the recorded markers `RESULT=777` and `RESULTS=SENTINEL`. Native reports division by zero; Py reports `E_ARITH`, with different diagnostic formatting. AFTER, DONE and post-error state are unobserved. The recorded finite case verdict is `matched_scoped`, not a claim of identical diagnostic text.

## PRINTVW wait and continuation

Native has two modes with one Return in an empty RichEdit; Py has two modes with one LF empty line on stdin. Before the helper: `A=0, RESULT=5, RESULTS=BEFORE`; the saved history contains a line `17`; after resumption: `A=1, RESULT=9, RESULTS=AFTER`, each once. The four saved `emuera.log` files have identical bytes but remain distinct recorded roles. Py process stdout includes an input prompt and is not asserted byte-identical to `emuera.log`. Native natural exit and exit code, GUI pixels and other PRINTV conditions remain unobserved.
