# 比較票・原ログ・fixtureの個別収録

[English](README.md) · [全資料をHTMLで読む](index.html) · [全体の閲覧ページ](../../docs/survey-browser.html)

旧形式226対象の証拠参照について、追加選定した2,020参照に対応する978ファイルを個別に確認しました。682ファイルは原バイト、296ファイルは私的な実行環境パス等を中立化した派生資料として収録しています。ファイル全体を非公開としたものは0件です。対象・役割の異なる参照は別IDで保持しています。

[index.json](index.json) に、ファイルごとの選定理由、検査内容、原本SHA-256、公開物SHA-256、加工箇所、参照する対象・参照IDを記録しています。HTMLページは全資料の本文を表示し、収録ファイルのダウンロード先も案内します。表示用JSONは整形しており、バイト照合は収録ファイルで行います。元の実行レシート・manifest・sealが本文にある場合、その値は元の記録に対するものです。派生物の封印として読み替えません。

## fixtureの復元

ERB・CSV 152ファイルについて、同ケースのERH・CSV・設定を照合し、[172通りの保存配置](fixture-layouts.json)を記録しました。既存公開物や今回の原票にない依存入力として、ARRAY180.ERH、ZZ269.ERH、CHARA1.CSVの3種類を元バイトで追加しています。復元先に必要な空のcsvディレクトリも作成します。

候補ルートから、未使用の出力フォルダーを指定します。

    python -B tools/restore_fixture.py U0157 --layout 0 --out C:/Temp/array180-input

これは入力を復元する操作です。エンジンは起動しません。出力先が存在する場合や入力のハッシュが異なる場合は拒否します。U0975は同ケースの設定を特定できておらず、その状態を配置索引と復元結果に表示します。他ケースの設定で補完していません。

## 検証と権利表示

    python -B tools/verify_saved_evidence.py

検証器は個別審査の978ファイル・2,020参照、収録バイト、HTML、加工対応、fixtureの依存物を照合します。元の694対象と2,898シナリオの判定は変更していません。保存された結果の再検査と、新しい実機実行は区別します。
