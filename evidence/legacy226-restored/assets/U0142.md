# ADDCHARA_POSTINC_ORDER_20261113

## 比較条件

`ADDCHARA A++,A++` を同一 ERB・CSV・設定で Native v24 を2回、公開 PyEmuera 3.0.0 pyz を1回実行した。公開pyzは実行前後ともSHA-256 `8a7b3697b97155c4dc994c8349c6756bb0401000d3bbccd8e85ff046e3774b35`。 Nativeの画面入力は送っておらず、ログと標準出力・標準エラーだけを保存した。

## 観測

All three runs (Native twice and public pyz once) reached the completion marker. Each reported A=10 before the command, A=12 and CHARANUM=2 after it, then NO0=10 and NO1=11. The two postfix increments return successive values and write the counter during evaluation; the second term sees the first increment. This confirms the selected two-term evaluation order and results, but not by itself whether character addition interleaves between term evaluations. Native raw logs are byte-identical and all three observed outputs match in this finite case.

## 判定範囲

これはADDCHARAの該当条件に限った、動的引数評価順序の一致観測である。関数呼び出しの副作用や失敗後の部分状態など、別の評価条件へ一般化しない。
