# PRINTKL のかな出力・改行比較（PRINTKL01）

Native Emuera1824+v24 と公開PyEmuera 3.0.0 pyz（SHA-256 `8a7b3697b97155c4dc994c8349c6756bb0401000d3bbccd8e85ff046e3774b35`）を同一fixture（CP932、SHA-256 `6fb07ed0d17092f3bc9b7f5bd0b8c1022f5e8dca0c769ebc36ecc7b198054572`）で比較した。元バイトとCP932復号結果は`FIXTURE_CP932_REPLAY.txt`にASCII形式で記録した。PyはCPython 3.12.10、source tree importなし。

`FORCEKANA 0`の後に`PRINTKL あアｱ A`、`PRINTFORML <PRINTKL_END>`、`INPUT`を実行する。Pyは保存入力42とQUITまで進み終了コード0。標準出力のCP932復号結果は`Now Loading...\r\n\u3042\u30a2\uff71 A\r\n<PRINTKL_END>\r\n42\r\n`で、PRINTKLの直後に改行して次の印字行へ移る。

Nativeは独立PID・デスクトップで2回実行。各probeには、その実行固有の出力クロップパス・SHA・寸法が直接JSONで記録され、fixture/exe/config前後SHAも一致した。各保持画像は420x130で、画面の該当出力領域だけを切り出し、`Now Loading`からかな行と`<PRINTKL_END>`行までを含む。

**判定: `matched_scoped`** — FORCEKANA 0のこの混在文字列に対するPRINTKL出力、および改行後に次の印字命令へ進む範囲。Native出力は視覚比較でありOUTPUTLOG原票とのバイト比較ではない。別かなモード、文字クラス網羅、式引数、折返し・幅・色・待機は未検証。製品コード変更なし。
