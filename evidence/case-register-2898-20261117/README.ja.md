# 2,898件ケース登録

[English](README.md)

この登録は有限範囲で選定したケースの索引です。verdictは各ケースに記録された範囲を示し、全機能の適合や実行完了を意味しません。実行モード数はプロセス起動回数ではありません。

旧case 68件では、ID・verdict・対象・参照先を保ち、取得手順の説明を短くしています。記録された部分観測と未到達・診断・未確認の制限は残し、後続caseは別実行として関連IDだけを示します。結果は旧caseへ転記しません。

116件の内訳は、過去の記録68件、元の有限比較範囲外だった42件、当初の対応関係が不明だった6件です。42件は元verdictを保持しています。元crosswalkのcase IDで照合すると、うち画像系38件には元の本家保存記録と限定的な観測があり、そのうちGCLEARの2件には別の後続本家GUI試行も記録されています。残る4件は `VARSAVE207_UNREACHED_PLAN`、`REFCOMMAND210_UNREACHED_REBIND`、`PRINTVKWC15`、`PRINTVDWC15` です。これは画像38件の資料範囲を示す区分であり、残る4件すべてが未観測という意味ではありません。元記録の観測範囲・未到達条件はcaseごとに異なります。待機2件には[通常待機後の観測](../wait-release-20261117/README.ja.md)と[空入力・診断の観測](../wait-c15-20261117/README.ja.md)が別資料にあり、後続記録も元verdictを置き換えません。画像38件の観測も限定状態に関するもので、対象全体の比較完了を意味しません。694 targetの有限範囲の比較完了や、6件の後続scope対応も、元verdictを成功へ変更するものではありません。

core.jsonl はID・verdict・target・pointerをまとめた検索用投影です。cases.jsonl は各ケースの条件と表示用情報を含みます。元raw・receipt・原票は同梱しません。snapshot/hashは同梱ファイルの識別と整合確認に使えますが、署名や発行者認証ではなく、記録された実行結果や互換性を証明するものでもありません。
