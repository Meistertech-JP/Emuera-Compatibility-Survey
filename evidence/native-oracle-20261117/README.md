# Saved Native Emuera observations

[日本語](README.ja.md) · [Guide](docs/native-oracle.md) · [Open the browser](docs/native-oracle.html)

An index for searching finite-condition inputs and saved Native Emuera output and diagnostics. PyEmuera comparison is supplementary. Case-specific reach, unknowns, shared conditions, and image limitations are shown in the browser.

This directory is an independently verifiable, browsable bundle of 113 selected rows (the existing 80 and 33 selected-observation projections); it does not claim to include the separate 34/38 cases.
